### 匯率修正（本輪最新，尚未 commit）
**問題**：首頁匯率顯示「1997」。

**原因一（資料層）**：`exchange_rate_snapshots` 表存有 CBC CSV 全部歷史資料（1993～今，共 8000+ 筆）。`getStoredRateTable()` 查詢沒有加 `LIMIT`，Supabase 預設只回傳 1000 筆，且排序從舊到新，所以拿到的是 1993～1997 的資料，`latest` 就是 1997 年。

**原因二（顯示層）**：1 JPY ≈ NT$0.1976，4 位小數顯示為「NT$0.1976」，使用者看成「1976」。

**修法**：
- `lib/exchange-rates.ts`：
  - `getStoredRateTable()` 改為 `.order('snapshot_date', { ascending: false }).limit(400)`
  - `storeRateTable()` 改為只 upsert 最近 400 筆（`STORE_DAYS_LIMIT = 400`）
- `app/_components/ExchangeRateCard.tsx`：
  - JPY 改為顯示「100 JPY = NT$19.76」而非「1 JPY = NT$0.1976」

修改後 `npx tsc --noEmit` 通過，尚未 commit 與部署。
