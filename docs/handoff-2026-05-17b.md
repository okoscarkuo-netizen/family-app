## 重要架構提醒

1. **Passcode Auth**：cookie 驗證，沒有 Supabase Auth
2. **Admin Client**：`createAdminClient()` 可能回傳 null，所有呼叫要先 null check
3. **family_accounts.id 是 text**，含特殊字元（如 `฿-`），URL 要用 `encodeURIComponent`
4. **`/api/accounts` REST route 保留**：`dashboard.tsx` 仍在使用
