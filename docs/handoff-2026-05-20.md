Preliminary findings from code review:

### 首頁 (`app/page.tsx`, `app/dashboard.tsx`)
1. `app/dashboard.tsx` is a very large legacy client component that owns dashboard, ledger, accounts, reminders, localStorage, and sync logic in one file. It should be split or replaced with smaller server-backed pages.
2. Home dashboard has separate local/client state from the real `/ledger`, `/ledger/new`, and `/accounts` server data. This can create inconsistent balances, entries, reminders, and account lists.
3. Home “記一筆” modal writes to local dashboard state, not the newer `family_transactions` flow used by `/ledger/new`. This is likely the biggest data-consistency issue.
4. Header date is hard-coded to `2026 年 5 月`; should derive from current date or selected period.
5. Exchange rates in `dashboard.tsx` are hard-coded. Either make them explicit as manual rates or move to a central configurable source.

### 記一筆 (`app/ledger/new/page.tsx`, `app/ledger/_components/TransactionForm.tsx`)
1. Category management was added, but icon uses inline SVG instead of an icon library; acceptable for now, but standardize later if the project adds `lucide-react`.
2. Category settings archive uses `window.confirm`; a project-style modal would be safer and more consistent.
3. Created/renamed categories update local state and call `router.refresh()`. Verify in-browser after login that picker selection stays stable after creating/deleting selected category.
4. Transfer transactions in `/ledger/new` do not use category picker; confirm whether transfer categories should remain hidden or be editable.
5. Merchant/category/account pickers are bottom sheets and may need mobile visual QA after login.

### 更多 (`app/more/page.tsx`)
1. Page is still mostly placeholder. It now links to reminders, but planned items like family settings, category management, import/export are not actionable.
2. Since category management now lives inside `/ledger/new`, consider adding a direct “分類管理” entry here later, or make More the central settings hub.
3. Bottom nav now treats `/reminders` as active under “更多”; confirm this product decision.

### 流水 (`app/ledger/page.tsx`, `TransactionList.tsx`, `TransactionFilters.tsx`)
1. Delete transaction is a plain form submit with no confirmation. Add confirm/modal to avoid accidental deletion.
2. Transfer list displays `⇄ amount` only. If filtered by account, show direction (`轉入` / `轉出`) based on `account_id` and `to_account_id`.
3. Filters keep `accountId` query param even when selecting “全部帳戶” because `updateParam` sets `accountId=` instead of deleting the param. Clean URL by deleting empty params.
4. Month/year parsing has no validation. Invalid query values can produce odd filters; clamp month to 1-12 and fallback year.
5. Transaction list does not show source/target account names, making transfers hard to audit.
