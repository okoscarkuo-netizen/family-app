# 交接文件 — 2026-05-17

## 專案目標
家庭記帳與管理 App。讓使用者管理家庭資產、記錄收支、以及管理家裡定期事務（地產稅、HOA、車子保養、冷氣維護等）。

## 技術架構
- **框架**：Next.js 16.2.6 + React 19 + TypeScript
- **樣式**：Tailwind CSS 4
- **資料庫**：Supabase（PostgreSQL）
- **認證**：Passcode 登入（不是 Supabase Auth），環境變數 `FAMILY_APP_PASSCODE`
- **Supabase 存取**：admin client（service role key），所有資料表透過 `lib/supabase/admin.ts` 的 `createAdminClient()` 存取

## 現有架構（重要！）

### 兩套並行的介面
| 路徑 | 說明 | 資料來源 |
|------|------|---------|
| `/ledger`（新）| 帳本模組，今日完成 | Supabase |
| `/accounts`, `/`（舊）| 全部在 `app/dashboard.tsx`（34K token 大檔案）| localStorage |

舊版 dashboard.tsx 的所有頁面只是 wrapper：
```tsx
// app/accounts/page.tsx
import { Dashboard } from "@/app/dashboard";
export default function AccountsPage() {
  return <Dashboard activePage="accounts" />;
}
```

### 重要架構注意事項
1. **Passcode Auth**：沒有 Supabase Auth，用 cookie 驗證 passcode
2. **family_* 系列表**：比照 `family_accounts` 模式，透過 admin client 存取，RLS 啟用但被 service role key bypass
3. **`family_accounts.id` 是 `text` 型別**（不是 uuid），FK 欄位要用 text
4. `createAdminClient()` 可能回傳 `null`（env var 未設定時），所有呼叫都要先檢查

### 現有資料
`lib/family-data.ts` 的 `initialAccounts` 有 105 個帳戶（從 AndroMoney 匯入），但還在 localStorage，尚未存進 Supabase 的 `family_accounts` 表。
